# 09 平台原型设计

产品名：**对译 Duiyi**
形态：iPhone 原生 App，竖屏锁定
新定位：多语言现场沟通**平台**。面对面、同声传译、会议记录是三个功能模块，不是三个独立 App。

可交互界面：[`../prototype/platform.html`](../prototype/platform.html)
架构：[`10-platform-architecture.md`](10-platform-architecture.md)
模块细则仍以 [`01-product-prototype.md`](01-product-prototype.md)、[`05-simultaneous-prototype.md`](05-simultaneous-prototype.md) 为准；本文只定**平台壳、任务、历史、总结、会议记录**。

---

## 1. 产品承诺

用户打开对译，先选「此刻要做什么」，再进入该模块干活。

| 模块 | 谁在用 | 屏幕 | 核心产出 |
| --- | --- | --- | --- |
| 面对面 | 两人隔桌 | 上下对半，上屏 180° | 双方各自看到译文 |
| 同声传译 | 一个人听现场 | 单栏正字 | 实时译文，可选耳机读出 |
| 会议记录 | 一个人记一场会 | 单栏正字，全文稿 | 完整文字稿 + 会后总结 |

三条共用：语种、权限、本机听写 / 翻译、任务与历史、总结与导出。

原则：

1. **操作简单**：每个模块主路径不超过「新任务 → 开始听 → 结束」。
2. **界面统一**：同一套色板、字号、中间大按钮；模块差异只在字幕怎么排。
3. **可扩展**：加一种语言或一个新模块，不改另外两个模块的 ViewModel。
4. **本机优先**：听写、翻译、任务都留在手机；总结能用 Apple 智能就用，不能用就说清楚，并允许导出分享。

## 2. 信息架构

```
启动
  ├─ 首次：欢迎 → 我看的语言 → 权限 → 下载模型 → 首页
  └─ 再次：首页

首页（新的主入口）
  ├─ 面对面
  ├─ 同声传译
  ├─ 会议记录
  ├─ 任务历史
  └─ 设置（语言包、字号、权限）

面对面 / 同声传译 / 会议记录
  ├─ 无任务：大按钮「新任务」
  ├─ 进行中：开始 / 暂停 + 「结束任务」
  ├─ 结束后：回首页或看刚保存的记录
  └─ 设置卡片（本模块语言、字号，不离开现场）

任务历史
  ├─ 按时间倒序，可按模块筛选
  └─ 一条记录：回看字幕 / 总结 / 导出分享 / 删除
```

首页替代现在「进 App 就掉进面对面或同声传译」。顶栏模式切换仍可留在模块内，作为快捷跳转，但**历史和会议记录必须从首页进**，避免三个功能挤在一个齿轮里。

## 3. 任务生命周期

任务是一次完整工作，不是一次点按听写。

```
未开始 ──新任务──► 进行中 ──结束任务──► 已保存（历史）
              │                    ▲
              └──暂停听写（任务仍在）─┘
```

| 动作 | 行为 |
| --- | --- |
| **新任务** | 若已有进行中的任务，先确认是否结束并保存，再开新的。新任务清空现场字幕，记下开始时间、模块、语种。 |
| **开始 / 暂停** | 只控制麦克风。暂停不等于结束，字幕还在，任务还在。 |
| **结束任务** | 停听写、归档字幕、写入本地历史。可选立刻打开总结。 |
| **进模块但没点新任务** | 不写历史。避免空记录。 |
| **切模块 / 进后台** | 进行中的任务保持「进行中」，听写暂停。回来可继续，或结束。 |
| **杀进程** | 下次打开：未正常结束的任务标为「未结束」，可继续或结束保存。 |

标题自动生成，用户不必起名：

- 面对面：`8月30日 面对面 · 中文 ↔ 英语`
- 同声传译：`8月30日 同声传译 · 英语 → 中文`
- 会议记录：`8月30日 会议 · 中文`；有内容后可用首句前 16 字作副标题

## 4. 各模块主界面（增量）

### 4.1 面对面 / 同声传译

现有字幕板、中间听写钮、语言条不变。只加一条很轻的任务条：

```
┌ 面对面                          历史  ┐
│  进行中 · 10:24                     │
│  [新任务]              [结束任务]    │
│  ──────── 上半屏字幕 ────────        │
│              ● 聆听中               │
│  ──────── 下半屏字幕 ────────        │
└─────────────────────────────────────┘
```

- **新任务**、**结束任务**用文字按钮，不要再做第三个大圆钮，避免和听写抢注意力。
- 无任务时，中间钮不可点，主操作是「新任务」。点过后才开始听（或进入可听状态）。
- 同声传译：**新任务仍不自动开听**，与现规则一致；用户再点中间钮。
- 面对面：新任务后可以按现偏好决定是否自动开听。

### 4.2 会议记录（新模块）

一个人记一场会。手机朝向自己，不要倒字，不要耳机朗读。

```
┌ 会议记录                     历史  ┐
│  进行中 · 中文 · 42 分钟          │
│  [新任务]           [结束任务]    │
│                                   │
│  完整文字稿（可滚动）              │
│  刚才那句用稍大字号                │
│                                   │
│              ● 录音中             │
└─────────────────────────────────────┘
```

产品规则：

1. 只选 **一种记录语言**（现场主要在说的语言）。需要译文时，结束后在记录里「译成我看的语言」，不在现场做同传。
2. 正文是**完整稿**，按句追加，不把中间修订拆成十几行。
3. 不读出、不回放录音。v1 只存文字，不存音频，降低隐私与体积。
4. 结束任务后进入本条记录：全文 + 总结 + 导出。

和同声传译的差别：同传追求「当下看懂」；会议记录追求「事后能读完、能总结」。

### 4.3 任务历史

一张列表，不要按模块拆三个入口。

每行：模块色点、标题、时长、语种、日期。左滑删除（系统确认）。点进去是只读回看，可总结、导出。

空状态：`还没有任务。从首页开一个新任务。`

## 5. 总结与导出

总结挂在**一条已结束的任务**上，不挂在「当前屏幕上的临时字幕」。

| 设备 | 点「总结」时 |
| --- | --- |
| 支持 Apple 智能且已打开 | 用本机模型写摘要，标明「由 Apple 智能生成」 |
| 支持但未打开 | 说明要到「设置 → Apple 智能与 Siri」打开；同时仍可导出 |
| **不支持（如 iPhone 13）** | **直接说本机没有 Apple 智能**，不要再写「打开即可」。给出导出 / 分享 |

总结页三块，从上到下：

1. 能力说明（一句，诚实）
2. 摘要正文（能生成才有；不能则不假装成摘要）
3. **导出文件 / 分享**（任何设备都有）

导出内容是一份 UTF-8 文本，用户可发给元宝、备忘录、微信、文件：

```
对译 · 同声传译
2026-08-30 10:18–10:44
英语 → 中文

文字稿
…

总结
…（若已生成）
```

分享走系统分享面板，不深链某个第三方 App。装了元宝即可在面板里选元宝。

## 6. 语言与扩展（产品侧）

现场语种（听 / 译 / 读）与 App 界面语种分开：

- **界面语种**：跟系统语言，用系统文案表，以后加法文界面不必改听写表。
- **现场语种**：现在 中文 / English / 日本語 / 한국어 / ไทย / Tiếng Việt。新语言 = 能力表多一行（听写、翻译、朗读是否可用），首页和选语种网格自动出现。

不可用的能力灰掉并说明「这台 iPhone 还没有这个语言模型」，不要让用户选了再失败。

## 7. 界面原则

- 色板沿用现有：画布 `#12141A`，正文 `#F4EFE6`，主操作金 `#E8B86D`。
- 首页用大卡片，一块模块一件事，不要宫格图标墙。
- 进行中的任务用一条细金线或「进行中」胶囊，不要全屏弹窗。
- 结束任务用二次确认（系统 `confirmationDialog`）：`结束并保存这条记录？`
- 动态字体、VoiceOver：模块名、新任务 / 结束、历史行都要有标签。
- 面对面倒字区域的按钮只放在下半屏用户侧，避免对方误触结束。

---

## 8. 明确不做（本阶段）

- 不把面对面和同声传译合成一个 ViewModel。
- 不存录音文件、不上云同步、不做账号。
- 不在 App 内嵌元宝 / 微信 SDK。
- 不做说话人分离（会议记录也不分「谁在说」）。
- 不在会议记录里做实时同传朗读。
