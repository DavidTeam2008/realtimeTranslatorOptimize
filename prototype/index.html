把手机平放在中间。

只懂中文的人和只懂英文的人相对而坐。下半屏正字给用户，上半屏倒字给对方。谁说话，对面就读到自己的语言。

低头看倒过来的字 → 正字

对方说中文用户下半屏出现英文
用户说英文对方上半屏出现中文
用户说中文对方上半屏出现英文

单麦克风不分说话人。用「我看的语言」+ 识别语种，决定字幕打在哪一侧。

主路径只有一个按钮。点按开始 / 暂停，长按打开设置。下面可以演练一轮中英对话。

交互备忘

  • 引导完成后自动进入聆听，减少桌上操作。
  • 字幕区不响应点按，避免平放误触。
  • 每侧只保留当前句 + 上一句，字号默认「更大」34pt。
  • 错误只出现在用户侧正字，对方侧保持干净。

视觉规范

桌面有反光，用深色暖白，不用霓虹。中英徽章靠色相区分，倒正方向才是主识别。

字号

  • 当前句默认 34pt Semibold（档位：标准 28 / 更大 34 / 最大 44）
  • 上一句 20pt Regular，对比 58%
  • 行距 1.25，左右 22pt

动效

  • 新句：180ms 淡入 + 4pt 位移
  • 中间结果只改文字，不跳布局
  • 跟随系统「减弱动态效果」
